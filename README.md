Análisis de Homicidios Domésticos a Mujeres en Ecuador

Este proyecto cumple con los objetivos del curso de Análisis de Datos. Se cargarán datos desde diferentes formatos (CSV, JSON, XML, SQLite y nube), se limpiarán, consolidarán, analizarán y visualizarán.

Fuentes de datos iniciales:

CSV: homicidios_mujeres.csv
Contiene información de homicidios por año, departamento, cantón y otros detalles desde 2017 hasta 2024.
