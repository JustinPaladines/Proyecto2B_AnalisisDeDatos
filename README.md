- Josselyn Reyes

## Descripción del proyecto
Este proyecto tiene como objetivo realizar un análisis de datos utilizando
múltiples fuentes de información y aplicando todas las etapas del proceso de análisis
de datos: carga, limpieza, consolidación, análisis y visualización.

El procesamiento de los datos se realizó mediante la herramienta **KNIME**, mientras
que los resultados obtenidos se desplegaron en un entorno web accesible a través de
**GitHub Pages**.



## Objetivo general
Analizar datos provenientes de distintas fuentes para obtener información relevante
mediante técnicas de limpieza, consolidación, análisis estadístico y visualización.



## Objetivos específicos
- Cargar datos desde diferentes fuentes (CSV, JSON, XML, bases de datos relacionales y NoSQL).
- Limpiar los datos eliminando duplicados y valores faltantes.
- Consolidar la información en un conjunto de datos unificado.
- Analizar los datos utilizando agrupaciones y estadísticas.
- Visualizar los resultados mediante gráficos.
- Desplegar los resultados en un servidor web.



## Fuentes de datos
Los datos utilizados en el proyecto provienen de distintas fuentes, entre ellas:
- Archivos CSV
- Archivos JSON
- Archivos XML
- Base de datos SQLite
- Base de datos NoSQL (MongoDB)

Los datos originales se encuentran en la carpeta: Datasets.zip
